區塊一-2｜大局觀：佈局階段的「聯合最佳化目標函數」拆解

OBJECTIVE FUNCTION · 佈局階段聯合最佳化
Total Cost =  α · Wirelength(HPWL) + β · Overlap_Density + γ · Routing_Congestion_Margin
α：線長拉力
HPWL = Σnet[(max x − min x) + (max y − min y)]
分段線性非凸函數，代表「要走的線有多長」。
β：空間不重疊
2D Bin 投影密度 ρ(x,y) 超過 1 的溢出面積。
代表「物理上塞不塞得下、還能不能合法化」。
γ：走線容錯
以 RUDY 模型預估的走線需求密度。
代表「後期還有沒有空間走線」。

為什麼 γ 必須「提前」到佈局階段？（華容道效應 Hua-Rong-Dao Effect）

如果佈局只最小化 HPWL（γ = 0），演算法會得到一個「每一步看起來都很聰明」的局部解： 把邏輯密度的 cell 全部往中心擠，因為中心到所有 net 的平均距離最短。 結果是 線長最短，但走線通道 100% 被塞死。 真正的代價要到 CTS / Routing 階段才會爆發，那時才發現無路可走， 必須整體重排佈局 —— 而重排時又會遇到同樣的擁塞， 演算法於是被困在一個只能整體退火 (global annealing) 才能爬出的局部極小值裡。

這正是 華容道 的結構：前期每一步都「正確」， 整體卻無解。把 γ（Routing Congestion Margin）提前納入佈局目標， 等於在還能低成本調整幾何位置時，就先主動撐開高密度區域、預留走線走廊， 避免後期陷入死胡同 —— 這就是「大局觀」的真正含義。

資料結構與檔案格式

  • Hypergraph (V, H)：V = cell 節點集、H = net 超邊集。佈局問題的抽象骨架。
  • Verilog / SystemVerilog：RTL 描述語言（對應編譯器前端）。
  • LEF：抽象 (Abstract) 與宏單元的幾何/接腳定義。
  • DEF：Design Exchange Format，記錄元件位置 (COMPONENTS/PLACEMENT)、接腳與 NETS。
  • GDSII：最終送到晶圓廠的幾何資料庫。
  • Liberty (.lib)：標準細胞的時序/功耗模型庫。

評估指標 (Metrics)

  • HPWL：Total Half-Perimeter Wire Length，佈局最通用的線長指標。
  • 2D Density Map：Bin 網格上的面積密度，用來抓重疊與局部擁塞。
  • RUDY：Routing Demand based on Bounding Box —— 以 net 的 bbox 預估走線需求密度。
  • Congestion Map / Overflow：需求 > 供給的通道（真正的可繞線性）。
  • Timing (WNS/TNS)：佈局後的關鍵路徑延遲與違例。
  • DRC/LVS Error Count：簽核階段的最終裁判。
RUDY(G) = Σnets [ pins(G) + Lnet · Area(G ∩ bboxnet) / Area(bboxnet) ]
// 長的 net 會把走線需求「攤平」到它跨越的所有 bin
c(G) = RUDY(G) / ( K · mean(RUDY) · FreeArea(G) )
// FreeArea(G) = max(0.15, 1 − 0.8·ρ(G))：cell 佔走的面積 = 被封死的走線通道
3

現代主流演進

  • Simulated Annealing（1980s–1990s）：離散交換 + Metropolis，早期 EDA 工業標準。
  • Analytical / Force-Directed：ePlace (SIGDAC'12) 用 Poisson 電場做密度排斥。
  • RePlAce / SimPlace (ICCAD'17/'19)：Nesterov 加速、連續到離散的混合流程。
  • DREAMPlace (ICCAD'19)：把佈局當成可微分 ML 最佳化，GPU 大規模並行。
  • 2020s：Chiplet / 3D-IC 異質整合、ML-based 拓樸與繞線、RL 代理模型。
趨勢一句話：從「離散隨機搜尋」→ 到「連續物理模型 + 硬體加速」→ 到「可微分 / 機器學習化」。 下面沙盒的 A / B / C 三種模式，正對應這三個世代。
